How it works

  1. HGVS is resolved to GRCh38 coordinates via Ensembl VEP, with the gene, exon and protein change.
  2. Reference sequence is pulled around the variant ({{ 'local genome' if env.genome_ready else 'Ensembl REST' }}).
  3. Primer3 picks pairs that keep the variant clear of both primers.
  4. Common variants under each primer are flagged from gnomAD allele frequencies.
  5. {% if env.blast_ready %}Primers are BLASTed genome-wide and paired into predicted amplicons.{% else %} In-silico PCR is off — install the local genome in Settings.{% endif %}
